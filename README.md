# Nebula · 樂理與創作的星際地圖

## 專案結構

```
index.html          頁面骨架、版面、三檔解說層級切換器、新主題與分析／五度圈模組
styles.css          星圖視覺、版面、動效與響應式樣式（原始主題）
themes.css          硬體極簡工業風、錄音室護眼模式、微擬物控制、懸浮播放條與視覺化樣式
levels.js           由 content/ 生成的三檔解說文本（請勿手改）
app.js              全部互動邏輯、音訊、樂譜與測驗
studio.js           主題管理、播放控制條、無干擾練琴、頻譜／泛音／色度分析、五度圈
content/
  core.json         層級設定、介面文案、音程／級數／Voicing／進行／知識文本
  chords.json       30 種和弦 × 3 檔解說
  modes.json        41 種調式 × 3 檔解說
tools/
  build-levels.js   把 content/*.json 合併生成 levels.js
  extract.js        從 app.js 抽出和弦／調式資料（維護用）
  data.json         抽取結果，供內容撰寫與校對
```

## 2026-11 正確性與可用性修正

本輪依《改進提示詞-主理整合》處理了會教錯內容與擋住操作的問題：

- **搜尋**：改成分詞與別名比對。輸入 `m7` 只會找到 m7（不會再誤中 `Cmaj7` 或 `dim7`）；`变化属`、`挂留`、`Cm7`、`Calt` 都能直接找到；輸入 `Cm7` 會自動把主音切到 C。
- **級數與記譜**：和弦音只保留一種寫法（Cm7 = `b3` Eb、`b7` Bb；Cdim7 減七度為 `bb7` A；Calt = `b9`/`#9`），不再出現 `m3 / b2 / 13` 互相打架或構造步驟錯位。
- **和弦定義**：`11` 改為省略三音的實務版；`13` 省略十一音；`7b13` 以 b13 取代純五；`alt` 文案明說本站示範 1-3-b7-b9-#9，不再聲稱包含未發聲的 b5/#5。
- **功能和聲**：級數依當前調式解析，`iii` 為主功能替代、`bVI` 為下屬借用、`bVII` 為借用屬功能；`I–bVI–bVII–I` 不再被標成四個主功能。進行盤補上 `iii` 與 `V`，預設改為 `I–vi–IV–V`，並新增王道進行 `IV–V–iii–vi`；空軌道不再顯示 46/100。
- **聲部工具**：兩個和弦都可獨立選根音（含 360 個根音×性質選項）；評分先檢查目標音是否屬於目標和弦；導音提示只在真正需要解決時出現；一鍵平滑會保留根音／三音／七音並重排合法目標音。
- **測驗**：作答前只顯示提示，不顯示答案；未作答時正確率顯示「—」而不是 100%；題幹不再洩漏功能類別。
- **音程**：可分辨增四度與減五度（依拼寫）、支援複音程（C4→E5 = 大十度），下拉含升降音名；參考卡可點擊驅動計算器，並提供「先後響／一起響」兩種試聽。
- **吉他**：A 型 6/9 指法重做；負相對品位改為升八度而不是截成空弦；Drop 2／Drop 3 與「省略五音」名實相符；悶音（x）播放改為短促噪音，不再發出空弦音高。
- **播放**：介面改稱「合成示意音」（不是原聲鋼琴／清音吉他）；新增「停止發聲」、換頁／重播／離開頁面自動消音；琴鍵改為按下發聲、放開收束；音域擴到 C3–C#5；人性化只作用於分解與掃弦，柱式和弦不會錯位。
- **交稿**：鋼琴 MusicXML 改為單部雙譜表（右手／左手＋backup），空小節輸出休止符，音名依調號拼寫（F 大調寫 B♭）；鋼琴 MIDI 改為右手／左手雙軌；列印預覽改為白紙黑譜。
- **資料保存**：新增「匯出工作區／匯入工作區」（偏好、樂句、譜例、播放設定）；本機寫入失敗會提示，不再默默吞掉。
- **首屏與版面**：頂欄不透明且壓成單列（其餘顯示設定收進 ⚙）、主音改成單一選擇、搜尋與 30 個和弦快速列置於首屏，鋼琴與五線譜一起入鏡；窄屏琴鍵改為真實黑白鍵比例的單排可滑動；繁體預設使用 PingFang TC／Noto Sans CJK TC／Microsoft JhengHei 字體棧。
- **無障礙**：分頁補上 `role="tab"`／`aria-selected`；快捷鍵與列印彈窗加上焦點圈；`Esc` 可退出練琴模式。

伺服器與網域層的項目（apex 轉址、HTTPS、快取與拆包、分享圖）見 [DEPLOYMENT.md](DEPLOYMENT.md)。



## 設定、語言與品牌標誌

右上角 **⚙ 設定** 統一收納介面主題（星雲／工業／錄音室）、解說層級、介面語言、升降號記譜、風格與核心調式；頂欄只保留設定、匯出、匯入與快捷鍵。

介面語言提供 **简体 / 繁體 / English**：

- English 會翻譯導覽、頁面標題、設定、和弦／音程／聲部等控制項、按鈕、即時回饋，以及和弦、調式、音程、樂理文章、測驗與樂句內容；和弦與調式名稱使用英文／國際術語。
- 英文內容由 `content/en/` 與 `levels-en.js` 提供，`en-map.js` 收錄介面與動態字串對照；切換語言時會同步重建頁面內容。
- 語言選擇寫入本機偏好，重新開啟仍會保留；英文重新載入不會回到中文。

左上角品牌標誌改為 56px、雙軌道與譜線構成的音符徽章，並依主題套用星雲紫靛、工業鋁灰／橘、錄音室深綠／螢光綠；游標移入時有浮起與光暈。

## 三種可切換主題

右上角「主題」可切換，選擇會寫入瀏覽器本機儲存（`music-dictionary-prefs-v1`），重新開啟仍會保留。

| 主題 | 視覺特徵 | 適合情境 |
| --- | --- | --- |
| 星雲星圖 | 原有深色星圖、紫靛光暈與星座連線 | 一般瀏覽與展示 |
| 硬體極簡工業風 | 霧面鋁金屬／消光白灰底、高飽和橘黃重點色、精細 1px 網格、等寬技術字體、方正 4–8px 圓角 | 白天、明亮的琴房或教學投影 |
| 錄音室護眼模式 | 極低眩光近黑底、示波器螢光綠／琥珀／電光藍微發光訊號線、掃描線與暗角、低對比鍵盤 | 長時間練琴、夜間編曲與混音 |

主題切換器本身即為微擬物打擊墊造型；`Alt + T` 可依序輪替三種主題。

## 現代微擬物觸覺控制

保留扁平介面的俐落，但把實體操作感補回細節：

- **BPM 旋鈕**：可上下拖曳、滾輪、方向鍵（`Home` / `End` 跳到 40 / 220）；雙擊回到 100，`TAP` 可連續點擊測速。
- **推桿**：音量推桿具內凹軌道與金屬握把投影，即時調整主輸出。
- **打擊墊**：播放／停止、節拍器、AB 循環與練琴模式皆為帶物理陰影與阻尼回彈的按鍵，按下時內凹並發出主題色微光。

## 懸浮毛玻璃播放控制條

固定在視窗底部的模組化控制條（可收合），包含：

1. **播放控制**：播放／暫停、停止、目前小節讀數。
2. **速度 BPM**：旋鈕、Tap Tempo，與譜例編輯器的速度欄位同步。
3. **節拍器**：開關、4/4 · 3/4 · 2/4 · 6/8 拍號、拍點指示燈（第一拍為重音）。
4. **AB 段循環**：`SET A` / `SET B` 標記目前小節、`↻` 啟用循環、`CLR` 清除；下方小節軌可點擊跳段，並顯示 A／B 標記。
5. **音量推桿**與目前和弦讀數。
6. **一鍵無干擾練琴模式**：隱藏側欄、頂欄與導覽，只留內容與控制條；`Alt + P` 或右上角「退出練琴模式」按鈕返回。

播放內容取自「功能和聲」目前的和聲進行；若進行為空，則以目前和弦循環。控制條設定儲存於 `nebula-studio-transport-v1`。

## 聲譜分析（SECTOR 07 · SIGNAL LAB）

「聲譜分析」星區提供三種互補視覺化：

- **即時頻譜**：Web Audio `AnalyserNode`（8192 點 FFT）搭配對數頻率軸 20 Hz–20 kHz，即時顯示低／中／高頻能量分布、峰值標記與頻段百分比；可調整主題後自動套用對應的訊號線色。
- **泛音列**：以目前和弦各音為基頻，顯示 2×、3×… 泛音柱，理論 1/n 衰減輪廓與實際量測能量對照。
- **色度圖（Chroma）**：將頻譜局部峰值映射到 12 個半音，繪製十二半音色度輪與能量條，並與目前和弦的理論音對照；同時以和弦模板即時偵測目前聽到的和弦名稱。

「持續發聲」會以三角波持續演奏目前和弦，方便觀察泛音結構與色度分布；也可直接播放和弦、音階，或用互動鋼琴／播放控制條製造訊號。

## 五度圈（SECTOR 04 · CIRCLE OF FIFTHS）

獨立模組，外圈為 12 個大調、內圈為關係小調，標示調號升降數：

- 點擊任一調區即時預覽該調資訊：調號、音階、主音、關係大小調、屬調、下屬調、平行調。
- 雙擊或按「設為主音」立即套用至全站主音與調式。
- 調內七個級數和弦可點擊試聽（I–IV–V–I 一鍵示範），並列出五度圈相鄰的轉調路徑（屬調、下屬調、上中音、下中音、降三度、升四度）。
- `大調 / 關係小調` 切換可對照同調號的兩個調。

## 三檔解說層級

右上角「解說層級」可切換：

| 層級 | 適合對象 | 文本策略 |
| --- | --- | --- |
| 初學者 | 零基礎 | 生活比喻、先講聽感與用法，術語第一次出現就翻成人話 |
| 學過樂理 | 有基礎 | 級數、功能、解決方向、具體進行與練習路徑 |
| 音樂人 | 創作／編曲 | 導向音、張力音、Voicing、替代與調式互換 |

選擇會寫入瀏覽器本機儲存，重新開啟仍會保留。和弦、調式、音程、級數、和聲進行、測驗提示、樂句引導、術語解析等區塊都會同步改寫。

修改文案後重新生成：

```bash
node tools/build-levels.js
```

## 互動與快捷鍵

- 點擊左側星區切換功能；網址會同步為 `#dictionary`、`#fifths`、`#analysis` 等，可用瀏覽器上一頁／下一頁。
- `Ctrl/Cmd + K` 或 `/`：聚焦和弦搜尋；`Enter` 直接選取第一個結果，`Esc` 清空。
- `?`：開啟快捷鍵指南；`Esc` 關閉彈窗、抽屜、清空搜尋或退出練琴模式。
- `Alt + 1…0`：跳到前 10 個星區；`[` / `]`：上一個／下一個星區（共 12 個）。
- `Alt + P`：切換無干擾練琴模式；`Alt + T`：輪替三種主題；`Shift + Space`：播放／暫停控制條。
- `A S D F G H J K`：在互動鋼琴上彈奏白鍵（`W E T Y U O` 為黑鍵；輸入框中打字時自動停用）。
- 行動版左側導覽改為抽屜，點擊背景、`Esc` 或關閉鈕即可收起。
- 已加入 `prefers-reduced-motion` 支援、鍵盤焦點樣式、跳至主要內容連結與列印樣式。

## 音訊與資料

- 全站聲音都是 Web Audio 振盪器即時合成的**示意音**，不是樂器取樣；介面不再標成原聲鋼琴／清音吉他。可按「停止發聲」或切換星區立即消音。
- 偏好、樂句與譜例只存在瀏覽器本機。右上角 `⬇`／`⬆` 可匯出／匯入整份工作區；清除網站資料前請先備份。
